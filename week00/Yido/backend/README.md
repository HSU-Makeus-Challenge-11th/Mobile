# 0주차 백엔드 - HTTP와 Postman 실습

코드 없이 Postman으로 API 요청을 보내 보는 실습이라, 실습 기록은 노션에 정리했습니다.

- 노션: https://app.notion.com/p/makeus-challenge/0-HTTP-Postman-3dab57f4596b805fab8bd4d69288dd68

## 실습 내용
- GET 요청으로 게시글 조회 (200 OK)
- Query Parameter로 조건에 맞는 데이터 검색
- POST 요청으로 게시글 등록 (201 Created)
- 없는 자원을 요청해 404 Not Found 확인
